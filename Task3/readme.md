# Задание 3. Создание векторного индекса базы знаний

Ниже приведена реализация индексации базы `knowledge_base/` в FAISS с локальными эмбеддингами. Решение ориентировано на дальнейшее использование в RAG: сохраняются метаданные (источник, id чанка, позиция в документе), индекс сохраняется на диск, есть пример поиска и мини-проверка качества.

---

## 1. Выбранная модель эмбеддингов

Использую локальную модель из Sentence-Transformers:

- Название: `sentence-transformers/all-MiniLM-L6-v2`
- Репозиторий: https://huggingface.co/sentence-transformers/all-MiniLM-L6-v2
- Размер эмбеддинга: 384

Почему она:
- быстрая на CPU
- компактные эмбеддинги (384)
- достаточно хороша для семантического поиска в RAG на старте
